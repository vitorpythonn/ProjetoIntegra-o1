# Objetivos

## Objetivo Geral

Desenvolver um Sistema de Controle de Chamados de Suporte Técnico que permita registrar, consultar e acompanhar solicitações de suporte de forma organizada, utilizando uma aplicação web integrada a um banco de dados.

## Objetivos Específicos

- Permitir o cadastro de usuários no sistema.
- Permitir a abertura de chamados de suporte técnico.
- Armazenar os chamados em um banco de dados SQLite.
- Permitir a consulta dos chamados cadastrados.
- Permitir que analistas atualizem o status dos chamados.
- Permitir o registro das soluções aplicadas aos chamados.
- Implementar autenticação para acesso às funcionalidades do sistema.
- Aplicar conceitos de desenvolvimento web, banco de dados, modelagem e testes estudados no curso de Análise e Desenvolvimento de Sistemas.
