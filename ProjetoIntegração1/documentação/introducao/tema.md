# Tema do Projeto

## Sistema de Controle de Chamados de Suporte Técnico

O projeto consiste no desenvolvimento de um Sistema de Controle de Chamados de Suporte Técnico, destinado ao registro, acompanhamento e consulta de solicitações de suporte.

A aplicação permite que usuários realizem seu cadastro e registrem chamados informando título, descrição, categoria e prioridade. Os chamados são armazenados em um banco de dados SQLite e podem ser consultados posteriormente.

O sistema também possui funcionalidades destinadas ao perfil de analista, permitindo a consulta dos chamados, atualização de seus status e registro das soluções aplicadas.

A aplicação foi desenvolvida utilizando Python e Flask no back-end, SQLite para armazenamento dos dados e HTML, CSS e JavaScript para a interface web.
