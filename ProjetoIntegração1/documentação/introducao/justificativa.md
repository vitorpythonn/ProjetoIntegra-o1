# Justificativa

O desenvolvimento de um Sistema de Controle de Chamados de Suporte Técnico justifica-se pela necessidade de organizar e centralizar o registro das solicitações de suporte.

A utilização de uma aplicação web permite armazenar as informações dos chamados em um banco de dados, facilitando sua consulta e acompanhamento.

O projeto também possibilita a aplicação prática dos conhecimentos adquiridos durante o curso de Análise e Desenvolvimento de Sistemas, envolvendo levantamento de requisitos, modelagem de dados, desenvolvimento de aplicações web, banco de dados, testes e controle de versão.

A escolha de Python, Flask e SQLite permite desenvolver uma solução funcional com uma estrutura simples, adequada ao escopo acadêmico proposto.
