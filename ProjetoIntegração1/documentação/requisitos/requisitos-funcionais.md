# Requisitos Funcionais

## RF01 — Cadastro de usuário

O sistema deve permitir o cadastro de usuários com nome, e-mail e senha.

## RF02 — Abertura de chamado

O sistema deve permitir que o usuário registre um chamado informando título, descrição, categoria e prioridade.

## RF03 — Consulta de chamados

O sistema deve permitir a consulta dos chamados cadastrados.

## RF04 — Atualização de status

O sistema deve permitir que o analista altere o status de um chamado.

## RF05 — Registro de solução

O sistema deve permitir que o analista registre a solução aplicada ao chamado.
