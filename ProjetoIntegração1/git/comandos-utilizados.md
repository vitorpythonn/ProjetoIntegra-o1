# Comandos Git Utilizados

Durante o desenvolvimento do Sistema de Controle de Chamados de Suporte Técnico, foi utilizado o Git para controle de versão do projeto e o GitHub para armazenamento do repositório remoto. O comando `git status` foi utilizado para verificar o estado atual do repositório, identificando arquivos novos, modificados ou pendentes de commit. O comando `git branch` foi utilizado para verificar a branch utilizada no desenvolvimento. Para adicionar os arquivos ao controle de versão, foi utilizado o comando `git add .`, responsável por adicionar os arquivos novos e modificados à área de preparação. Após a preparação dos arquivos, foram realizados commits utilizando o comando `git commit -m "mensagem do commit"`, registrando as alterações realizadas no histórico do projeto. Entre os commits realizados está o registro `Finaliza sistema de controle de chamados`. A conexão entre o repositório local e o repositório remoto foi verificada utilizando o comando `git remote -v`. Para enviar os commits para o GitHub, foi utilizado o comando `git push origin main`, responsável por atualizar a branch `main` do repositório remoto. O histórico de alterações foi consultado utilizando o comando `git log --oneline`, permitindo visualizar de forma resumida os commits realizados durante o desenvolvimento. Ao final das alterações, o comando `git status` foi utilizado novamente para verificar a situação do projeto. O resultado apresentado foi `On branch main`, `Your branch is up to date with 'origin/main'` e `nothing to commit, working tree clean`, indicando que não havia alterações locais pendentes e que a branch local estava sincronizada com o repositório remoto.
